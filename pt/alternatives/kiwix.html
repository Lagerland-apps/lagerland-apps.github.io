Wikipédia · Para descobrir · Sem anúncios · iPhone e iPad

Um complemento do Kiwix
para uns quantos artigos novos por dia.

O Kiwix é a app para ler a Wikipédia totalmente offline. Descarrega-se um ficheiro ZIM e lê-se a enciclopédia inteira sem ligação, o que é difícil de superar para viajar, para zonas remotas e para locais sem internet. O WanderWiki serve para outra coisa. Transforma a API da Wikipédia num feed de descoberta para deslizar, sem anúncios nem conta, e permite guardar artigos para ler offline. As duas convivem bem.

Em que difere o WanderWiki do Kiwix?

O Kiwix é uma cópia descarregada e o WanderWiki, um feed de descoberta online.

Função principal
WanderWiki: descobrir. Desliza-se um baralho de artigos aleatórios, por temas e de «Hoje na história», e «E a seguir?» propõe três artigos relacionados debaixo de cada um que se lê.

Kiwix: consulta offline, uma enciclopédia completa descarregada onde se pode pesquisar em qualquer lado.
Como funciona offline
WanderWiki: API online; guardam-se artigos para os ler offline.

Kiwix: ficheiro ZIM completo no dispositivo, por isso tudo funciona offline.
Espaço
WanderWiki: leve, porque só os artigos guardados ocupam espaço.

Kiwix: pesado, porque os ficheiros têm muitas vezes vários gigabytes.
Preço
WanderWiki: grátis para 20 artigos por dia; o Premium custa {P_MONTHLY@wanderwiki}/mês, {P_YEARLY@wanderwiki}/ano ou {P_LIFETIME@wanderwiki} na opção vitalícia.

WanderWiki ou Kiwix: qual escolher?

O WanderWiki serve para quem…
  • quer uns quantos artigos novos para ler todos os dias no telemóvel
  • quer um baralho para deslizar, sem anúncios, com «Hoje na história» e feeds por temas
  • só precisa de guardar alguns artigos para os ler offline
  • prefere uma app leve, sem um ficheiro de vários gigabytes
  • gosta de artigos lidos em voz alta, de um leitor que retoma onde a leitura parou e da história do dia num widget
O Kiwix serve para quem…
  • precisa da enciclopédia inteira offline, para viajar, para zonas remotas ou para quando não há dados
  • quer pesquisar offline em toda a Wikipédia
  • vai preparar um dispositivo para locais com pouca ligação ou sem ela
  • quer um leitor de cópias offline grátis e de código aberto

As duas funcionam bem lado a lado: o Kiwix para quando não há ligação e o WanderWiki para ler todos os dias.

Perguntas

Perguntas frequentes

O WanderWiki substitui o Kiwix?
Não. O Kiwix é a app de referência para ler a Wikipédia totalmente offline: descarrega-se um ficheiro ZIM completo e lê-se a enciclopédia inteira sem qualquer ligação. O WanderWiki é um leitor para descobrir artigos, que os obtém online pela API da Wikipédia: um baralho para deslizar, em que se podem guardar artigos para ler offline. Para a enciclopédia inteira offline, o Kiwix é a ferramenta certa.
O que faz o WanderWiki que o Kiwix não faz?
Ajuda a encontrar artigos que não se procuravam. O Kiwix serve para consultar uma cópia descarregada. O WanderWiki dá um feed de artigos aleatórios para deslizar, baralhos por temas, «Hoje na história» e uma mistura «Para Si» com os temas escolhidos, sem anúncios nem conta. É para quando se quer que a Wikipédia surpreenda; para ter um artigo concreto offline num avião, use o Kiwix.
O WanderWiki lê a Wikipédia toda offline como o Kiwix?
Não da mesma maneira. O Kiwix guarda um ficheiro ZIM completo (muitas vezes com vários gigabytes) para que tudo fique disponível sem ligação. O WanderWiki obtém os artigos online, pela API da Wikipédia, e descarrega o texto completo dos artigos guardados, que por isso abrem offline. Serve como lista de leitura, mas não como enciclopédia completa offline.
O WanderWiki é grátis como o Kiwix?
O Kiwix é grátis e de código aberto. O WanderWiki é grátis para 20 artigos por dia; o Premium, que acrescenta «Para Si», «Hoje na história» e o deslize ilimitado, custa {P_MONTHLY@wanderwiki}/mês, {P_YEARLY@wanderwiki}/ano ou {P_LIFETIME@wanderwiki} na opção vitalícia. Nenhum plano mostra anúncios. As duas apps servem para coisas diferentes, e os preços também são diferentes.
O WanderWiki usa conteúdo real da Wikipédia?
Sim. O WanderWiki usa a API pública da Wikipédia para obter artigos reais, o mesmo conteúdo que o Kiwix arquiva, em 32 edições da Wikipédia, sem anúncios nem conta. Apresenta-os como um baralho de descoberta online, enquanto o Kiwix dá uma cópia descarregada.
Vale a pena usar o Kiwix e o WanderWiki em conjunto?
Funciona bem. Guarde o Kiwix para quando não há mesmo ligação, como numa viagem sem dados, em trabalho de campo numa zona remota ou numa emergência, e use o WanderWiki no dia a dia para ler sem anúncios no iPhone ou no iPad. Um serve para consultar offline, o outro para ler o que aparecer.
