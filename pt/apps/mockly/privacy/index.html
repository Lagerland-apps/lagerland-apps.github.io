O que fica no Mac e o que vai para o fornecedor de IA ou para a Apple, se o decidir." keywords: - "mockly política de privacidade" - "mockly privacidade" - "mockly dados pessoais" - "app de capturas de ecrã para a app store" - "app sem seguimento" overview: > O Mockly é uma app para macOS pensada para ajudar programadores e designers a criar capturas de ecrã para a App Store com rapidez e rigor. A privacidade é uma parte central da conceção da app. Esta política explica que informações o Mockly trata, como são utilizadas e que opções o utilizador tem. data_collection: > O Mockly trata apenas as informações que o utilizador decide fornecer, como imagens, capturas de ecrã, textos, composições e ficheiros de projeto criados ou importados pelo próprio utilizador na app. O Mockly não recolhe dados pessoais, dados de análise de utilização nem dados comportamentais para fins de publicidade ou de definição de perfis. data_storage: > Os projetos, as imagens e as composições são guardados localmente no Mac, nos ficheiros que o utilizador guarda. As definições, como o fornecedor de IA e o modelo escolhidos, ficam nas preferências da app no Mac. As chaves de API dos fornecedores de IA e a chave de API do App Store Connect do utilizador são guardadas no porta-chaves do macOS. O Mockly não tem conta e a Lagerland Apps não tem nenhum servidor que receba os dados do utilizador. Se o utilizador decidir guardar ficheiros no iCloud Drive ou noutro armazenamento na nuvem, essa gestão cabe à Apple ou ao fornecedor de armazenamento escolhido. third_parties: > O Mockly não utiliza serviços de terceiros de análise, SDK de publicidade nem serviços de seguimento, e nunca envia dados do utilizador para um servidor da Lagerland. O Mockly só envia dados quando o utilizador usa uma destas funcionalidades. A tradução com IA envia o texto que o utilizador pede para traduzir, e os idiomas de destino, ao fornecedor de IA escolhido (Anthropic, OpenAI ou Google), com a chave de API do próprio utilizador e segundo os termos desse fornecedor. O envio para o App Store Connect envia as capturas de ecrã que o utilizador carrega diretamente para a API do App Store Connect da Apple (api.appstoreconnect.apple.com), com autenticação através de um token criado a partir da chave de API do App Store Connect do utilizador; a chave privada em si nunca é enviada. A opção de enviar comentários abre a app de e-mail do próprio utilizador com a versão da app, a versão do macOS e o idioma já preenchidos; nada é enviado até o próprio utilizador enviar o e-mail. A Apple pode tratar dados limitados no âmbito dos serviços do sistema que o utilizador decida usar, como as compras integradas (StoreKit), as classificações ou as transferências da App Store. O Mockly não tem acesso aos dados de pagamento do utilizador. sensitive_data: > O Mockly não recolhe nem trata dados pessoais sensíveis, como informações de saúde, dados de localização, contactos ou identificadores. O conteúdo que o utilizador cria na app fica no Mac, a menos que o traduza com IA ou o envie para o App Store Connect, como descrito acima. children: > O Mockly não se dirige a crianças com menos de 13 anos. A app não recolhe conscientemente dados pessoais de crianças. changes: > Podemos atualizar esta política de privacidade de tempos a tempos. Quaisquer alterações serão refletidas nesta página e a data de «Última atualização» será revista em conformidade. ---
