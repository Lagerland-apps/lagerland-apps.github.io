Comment utiliser le code

  1. Touchez « Obtenir à moitié prix » à côté de l’app qui vous intéresse, sur l’iPhone, l’iPad ou le Mac où vous l’utilisez. Sur un ordinateur, ouvrez le QR code et scannez-le avec votre iPhone.
  2. Vérifiez le prix et confirmez. L’App Store affiche la moitié du prix à vie habituel de votre pays, et vous le payez une seule fois.
  3. Ouvrez l’app. Le déblocage est actif. Si ce n’est pas encore le cas, touchez « Restaurer les achats » dans les réglages de l’app.

Les {{ bf.count }} offres

Les prix indiqués sont ceux de l’App Store français. Dans chaque pays, c’est le prix à vie local qui est divisé par deux, et l’App Store affiche le vôtre avant que vous confirmiez.
