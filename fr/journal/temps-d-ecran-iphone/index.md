Temps d’écran est intégré à l’iPhone. Il montre le temps passé dans les apps et sur les sites web, et sert à répartir ce temps par catégorie d’apps ou à choisir les moments où elles sont disponibles. Cette page suit le guide d’utilisation de l’iPhone d’Apple en français, pour iOS 27 (consulté le 8 novembre 2026). Avec iOS 27, Apple a renommé plusieurs réglages : les anciens noms sont rappelés juste en dessous, pour les iPhone restés sur une version antérieure.

## Les noms selon la version d’iOS

| Ce que fait le réglage | iOS 27 (guide actuel) | iOS 26 et versions antérieures (anciens noms) |
|---|---|---|
| Moments de la journée où des apps sont disponibles | « Programme de temps d’écran » | « Temps d’arrêt » |
| Durée d’utilisation par catégorie d’apps | « Temps accordés » ou « Temps autorisés » | « Limites d’app » |
| Apps utilisables et contacts joignables à tout moment | « Toujours autorisées » | « Toujours autorisées » |

Le guide d’iOS 27 écrit tantôt « Temps accordés », tantôt « Temps autorisés » : suivez le libellé que votre iPhone affiche. D’après ce guide, les programmes et les temps accordés demandent la version 27 (ou ultérieure) d’iOS, d’iPadOS, de macOS, de watchOS et de visionOS sur tous vos appareils Apple, et, avec un groupe de partage familial, sur tous les appareils du groupe. Si votre iPhone est resté sur iOS 26, le [guide d’Apple pour iOS 26](https://support.apple.com/fr-fr/guide/iphone/iphb0c7313c9/26/ios/26) décrit les étapes de « Temps d’arrêt » et de « Limites d’app ». Tout ce qui suit vaut pour iOS 27.

## Activer Temps d’écran et lire les résumés

D’après le [guide d’Apple](https://support.apple.com/fr-fr/guide/iphone/iphbfa595995/ios) : ouvrez Réglages, touchez « Temps d’écran », puis « Programme de temps d’écran », « Temps accordés » ou « Gérer le temps d’écran », et touchez « Activer Activité dans les apps et sur les sites web ». Pour lire vos données, touchez « Moyenne quotidienne », puis Semaine ou Jour. Plus bas sur la même page, un rapport compte vos activations de l’appareil et les notifications reçues.

Un rapport hebdomadaire arrive par une notification, « Rapport hebdomadaire de Temps d’écran ». Un widget « Temps d’écran » sur l’écran d’accueil affiche les données d’utilisation en un coup d’œil.

## Régler les programmes et les temps accordés

Le [guide d’Apple](https://support.apple.com/fr-fr/guide/iphone/iphb0c7313c9/ios) distingue deux outils : les temps accordés fixent la durée d’utilisation quotidienne, les programmes fixent les moments où les apps sont utilisables. Pour un programme, touchez « Temps d’écran », « Programme de temps d’écran », activez Programme, puis « Ajouter un programme » et choisissez les jours. Chaque plage horaire reçoit un nom, des heures de début et de fin et des catégories de temps accordé.

Pour les temps accordés, touchez « Temps d’écran » puis « Temps autorisés ». Les catégories citées par Apple sont Divertissement, Jeux et « Réseaux sociaux ». Un curseur règle la durée totale ou celle d’une catégorie, et « Gérer les catégories » en crée de nouvelles. Chaque app d’une catégorie reste utilisable jusqu’à la limite de la catégorie ou jusqu’au total quotidien. Si l’app déclare un site web associé, le temps accordé s’applique aux deux.

« Toujours autorisées » liste les apps que vous pouvez utiliser et les contacts avec qui vous pouvez communiquer à tout moment, quels que soient les programmes et les temps accordés. Apple donne comme exemple des membres de la famille ou l’app Santé.

## Quand une limite est atteinte

Les pages d’Apple pour iOS 27 consultées pour cet article ne décrivent ni ce qui s’affiche quand une limite ou un programme s’applique, ni les boutons proposés à l’écran. Cette page ne les décrit donc pas. Le guide d’iOS 26 indique, lui, que par défaut les limites de « Temps d’écran » peuvent être ignorées une fois atteintes, et que l’option « Bloquer l’appareil » de « Temps d’arrêt », proposée quand un code de « Temps d’écran » est défini, empêche certaines apps de s’ouvrir pendant le temps d’arrêt. Sous iOS 27, le code décrit ci-dessous protège vos réglages.

## Le code Temps d’écran

D’après le [guide d’Apple sur le code](https://support.apple.com/fr-fr/guide/iphone/iph272b4c4bd/ios), un code à quatre chiffres doit être saisi avant de pouvoir modifier les réglages que vous avez choisis pour vous-même. Pour le créer : « Temps d’écran », « Code et gestion », « Verrouiller les réglages “Temps d’écran” », puis le code, deux fois. Une fois le code défini, vous pouvez aussi configurer un « Code de secours pour “Temps d’écran” » : il permet de réinitialiser le code avec votre compte Apple en cas d’oubli.

Pour le modifier : « Code et gestion », puis « Modifier le code de “Temps d’écran” ». Pour le supprimer : « Code et gestion », « Modifier le code de “Temps d’écran” », « Désactiver le code de “Temps d’écran” », puis le code actuel.

## Partager entre les appareils

Selon le guide d’Apple, « Partager entre les appareils » (dans « Gérer le temps d’écran ») synchronise les réglages et les rapports entre les iPhone, iPad et Mac connectés au même compte Apple. Les limites et les programmes s’appliquent alors à tous ces appareils, et l’activité peut s’afficher combinée. Si vous désactivez l’option, chaque appareil garde ses propres réglages de « Temps d’écran ». Cette option demande elle aussi la version 27 des systèmes sur tous vos appareils Apple.

## Désactiver Temps d’écran

D’après le guide, dans Réglages, touchez « Temps d’écran », puis, selon ce que vous voulez arrêter :

- Temps d’écran entier : « Gérer le temps d’écran », puis « Désactiver Activité dans les apps et sur les sites web ».
- Le programme : « Programme de temps d’écran », puis désactivez Programme.
- Un temps accordé : « Temps accordés », « Gérer les catégories », la catégorie, puis « Supprimer la catégorie ».

## Contenu et confidentialité, et comptes d’enfants

Le réglage « Contenu et confidentialité » de « Temps d’écran » ouvre les « Restrictions de contenu » (Livres, Films, Séries TV, Musique) et « Autres fonctionnalités » (AirDrop, Caméra, par exemple), d’après le [guide d’Apple](https://support.apple.com/fr-fr/guide/iphone/iph3ff83f3b1/ios).

Pour un enfant, Apple décrit un autre parcours : le [partage familial](https://support.apple.com/fr-fr/108806) avec un compte Apple propre à l’enfant, puis Réglages, Famille, le nom de l’enfant et « Temps d’écran ». Cette page ne traite pas du contrôle parental.

## Quand Temps d’écran ne suffit plus

Temps d’écran mesure et limite. Il ne change pas ce qu’il faut faire pour rouvrir une app. Si cela vous manque, [l’application pour limiter le temps d’écran sur iPhone](/fr/guides/limiter-temps-ecran-iphone/) compare les outils, l’article sur [ce qu’une app peut bloquer](/fr/journal/what-an-iphone-app-can-actually-block/) explique les limites techniques d’iOS et celui sur [le coût du déverrouillage](/fr/journal/unlock-cost-outside-the-app/) explique pourquoi ce coût doit se trouver hors de l’app.

[EarnLock](/fr/apps/earnlock/) est l’app de Lagerland Apps sur ce terrain. Elle verrouille des apps ou des catégories avec les contrôles Temps d’écran d’Apple, pour votre propre iPhone, et n’est pas une app de contrôle parental. À la moitié de l’objectif quotidien d’activité, une partie des apps verrouillées s’ouvre pour environ une heure, une fois par jour. À l’objectif complet, tout s’ouvre jusqu’à minuit. Bloquer une app ou une catégorie est gratuit, sans limite de durée ; Premium ajoute notamment les apps en nombre illimité et l’app Apple Watch. Aucun compte n’est nécessaire et rien ne quitte l’iPhone. EarnLock s’appuie sur Temps d’écran et ne le remplace pas.
