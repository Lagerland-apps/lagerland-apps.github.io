Why does EarnLock use Apple's Family Controls instead of an Accessibility-based blocker?
On iOS, Family Controls (ManagedSettings + DeviceActivity + ShieldConfiguration) is the only Apple-sanctioned API for blocking arbitrary apps systemwide. It lets the custom shield show a live progress ring on every blocked app, where a workaround could only nag the user after the fact. The catch is that Family Controls hands EarnLock opaque tokens, so even EarnLock cannot see which apps you blocked. That is also why EarnLock has nothing to send to a server even if it wanted to. WalkMyScreen on Android uses a different API surface; the iOS port (when it ships) will need to use Family Controls too.
