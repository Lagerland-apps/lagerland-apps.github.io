An Itsyconnect alternative
for apps that sell in-app purchases.

Itsyconnect is a good App Store Connect client, and it's free. Nick Ustinov publishes it under the MIT license, and it covers releases, TestFlight, reviews, analytics and an MCP server for coding agents. AppMeta does the same everyday listing work in a native SwiftUI app and goes further into In-App Purchases, subscription groups and Game Center. It also costs money, so here is where each one is the better pick.

How does AppMeta compare to Itsyconnect?

Both are Mac apps that talk to Apple's App Store Connect API with your own key. The differences are price, how they're built, and how much of the store setup beyond the listing they reach.

Price and license
AppMeta: $17.99/year or $29.99 lifetime. The free download runs in demo mode with sample data; connecting your own account needs Pro. Closed source.

Itsyconnect: Free, with no limit on apps or developer accounts. MIT-licensed, so you can read the code that handles your API key.
How it's built
AppMeta: SwiftUI and SwiftData, macOS 14 Sonoma or later, sold on the Mac App Store.

Itsyconnect: Electron with a Next.js and React interface, macOS 11 or later, distributed as a signed DMG on GitHub. It can also run as a Docker web app.
In-app purchases and Game Center
AppMeta: Creates and edits In-App Purchases, subscriptions and subscription groups: localizations, prices, territory availability, introductory offers and the review screenshot Apple asks for. Also Game Center achievements, leaderboards and leaderboard sets.

Itsyconnect: Not supported today. Its README doesn't list them and its source has no modules for IAPs, subscriptions or Game Center.
Checking changes before a push
AppMeta: Every changed field shows the live App Store Connect value next to your edit. Push one field, one locale or all locales, and fields that changed on the server since your last fetch are flagged.

Itsyconnect: An opt-in diff mode stages changes locally, shows a before/after view, lets you discard single fields, then pushes everything at once.
AI
AppMeta: Your own key for Anthropic, OpenAI or Google, a local model through Ollama or LM Studio, or Apple Intelligence on-device on macOS 26.

Itsyconnect: Your own key for Anthropic, OpenAI, Google, xAI, Mistral or DeepSeek, plus AI translation of the text inside screenshots.
Analytics and automation
AppMeta: Sales and subscription analytics, an App Store funnel (impressions, page views, downloads) and performance diagnostics with hang and disk-write call stacks. No MCP server.

Itsyconnect: A wider analytics view (impressions, sessions, conversion funnel, portfolio proceeds) and an MCP server for Claude Code, Codex, Cursor and OpenCode.

Who should pick AppMeta and who should pick Itsyconnect?

Pick AppMeta if…
  • You sell in-app purchases or subscriptions and want to edit them with the same locale workflow as your listing
  • You ship Game Center achievements or leaderboards
  • You want AI that stays on the Mac, through Apple Intelligence or a local model
  • You want to push one field or one locale at a time
  • You prefer a SwiftUI app installed from the Mac App Store
Pick Itsyconnect if…
  • You want a free tool, or one whose source you can audit
  • You want an MCP server so a coding agent can edit your listings
  • You want the deeper analytics dashboard and TestFlight tester feedback
  • You want a self-hosted web version, or you're still on macOS 11 to 13
  • Your apps don't sell in-app purchases or use Game Center

Both use the App Store Connect API with your own key, so trying one doesn't lock you out of the other.

FAQ

What is the best Itsyconnect alternative for Mac?
If you need In-App Purchase, subscription or Game Center editing, AppMeta is the closest alternative. It's a native SwiftUI client for the App Store Connect API that edits all 50 locales side by side and shows each change next to the live value before it pushes. If you only need listing metadata, releases, TestFlight and reviews, Itsyconnect already does that well for free.
Is Itsyconnect free?
Yes. Itsyconnect is free with no limit on apps or developer accounts, and its source is MIT-licensed on GitHub. Earlier 2026 versions had a paid Pro tier, which was dropped in May 2026. AppMeta costs $17.99/year or $29.99 lifetime, and its free download runs in demo mode with sample data.
Is Itsyconnect a native Mac app?
It's a desktop Mac app, but it's built on Electron with a Next.js and React interface rather than SwiftUI or AppKit. That shared web stack is also what lets it run as a Docker web app. AppMeta is written in SwiftUI with SwiftData. For many people the feature differences will matter more than the stack.
Does Itsyconnect manage In-App Purchases, subscriptions or Game Center?
Not as of October 2026. Its README and source don't include IAP, subscription or Game Center editing. AppMeta creates and edits In-App Purchases, subscriptions and subscription groups (localizations, prices, territory availability, introductory offers and the review screenshot), plus Game Center achievements, leaderboards and leaderboard sets.
Does AppMeta have an MCP server like Itsyconnect?
No. Itsyconnect ships an optional MCP server that lets Claude Code, Codex, Cursor or OpenCode read and update listings, and it respects diff mode. AppMeta has no MCP server today. If editing App Store Connect from a coding agent is central to how you work, Itsyconnect is the better fit.
Can I use AppMeta and Itsyconnect on the same app?
Yes. Both use the App Store Connect API with your own key and keep their working copy on your Mac. If you edit a field in one, refresh the other before pushing. AppMeta flags fields that changed on App Store Connect since your last fetch, so you don't overwrite a newer value by accident.
