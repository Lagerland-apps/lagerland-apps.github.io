Native Mac · App Store Connect API · Keychain-secured

App Store Connect,
without the browser.

If you ship indie iOS apps, you know the App Store Connect web UI: six browser tabs open, metadata edits spread across languages, and page reloads that lose your place. AppMeta is a native Mac client for the App Store Connect API that takes over the worst of that work.

How does AppMeta compare to App Store Connect on the web?

Everyday speed
AppMeta: A native SwiftUI app that switches instantly between languages, apps, and versions.

ASC web: A page load for each action, layout changes every so often, and sessions that log you out.
Localisation workflow
AppMeta: Pick a field and every language's version of it sits in one view, editable in place. Apply one value to every locale, or copy from the previous version.

ASC web: One language at a time from a dropdown, which gets tedious for apps in many languages.
Safety
AppMeta: A diff preview before you submit shows exactly what is about to change on the App Store.

ASC web: There is no built-in diff, and mistakes are easy to make on dense metadata pages.
Credentials
AppMeta: Credentials sit in the Keychain, and API calls go straight from your Mac with no server in the middle.

ASC web: Apple ID session cookies in your browser.

Who should pick AppMeta vs the ASC web UI?

Pick AppMeta if…
  • You edit metadata across multiple apps or languages regularly
  • You've made a mistake on the ASC web UI and wished for a diff preview
  • You'd like a desktop tool with a one-time lifetime option for work you now do in the browser
  • You work in SwiftUI and want your tools to feel native
Stick with ASC web if…
  • You edit metadata once every few months, too rarely to justify a native app
  • You need the parts AppMeta leaves to the website, such as App Privacy details, TestFlight tester management or App Preview videos
  • You work on a team with approval workflows specific to the ASC web UI

Questions

FAQ

Is there a native Mac app for App Store Connect?
Yes. AppMeta is a native macOS app that connects to the App Store Connect API and lets you edit app metadata, localisations, versions, and in-app purchases locally. It stores credentials in Keychain and shows a diff preview before changes are pushed.
Why use AppMeta instead of the App Store Connect website?
AppMeta replaces the browser workflow for everyday metadata editing. It's faster, shows every language of a field at once, shows a diff before you submit, and isn't affected by the periodic redesigns and inconsistencies of the App Store Connect web UI. It's meant for indie developers who edit metadata often.
Does AppMeta store my App Store Connect credentials?
Credentials are stored in the macOS Keychain. Requests go directly from your Mac to the App Store Connect API, with no Lagerland server in between.
Does AppMeta replace Fastlane?
No, the two work alongside each other. Fastlane automates release workflows from the command line, and AppMeta is a GUI for the everyday editing most developers still do by hand. Many indie devs use both.
