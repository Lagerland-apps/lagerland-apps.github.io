Three styles for every page. You pick one.

The studio site and each of the {{ app_count }} app pages get their own world. Every app becomes a standalone microsite with its own navigation, type and page structure; only a thin footer strip links back to Lagerland. Every style keeps the permalinks, the seo/schema/quick_answer structure and the App Store elements (official badge, Smart App Banner, desktop QR, sticky bar, price).

  1. Read the three style cards for a page. Each preview shows the style's typefaces and colours; "Full style card" has the first-viewport layout, page sequence and signature move.
  2. Pick one with its button. You can change a pick at any time. Use the note box to steer it, for example "style B, but with A's navigation".
  3. Picks save automatically. Claude reads them before the first build phase starts. Nothing is built until you approve the plan at the bottom.

Connecting to the shared store…

Specimens, not sketches

Each preview sets the page's real headline in the style's real typefaces and colours. Full HTML sketches were stopped to save session credits; they get built only for the styles you pick, in that page's phase.

How the three were chosen

For each page, seven directions were drawn from the audience's own world and ranked. A dice roll chose style A from that list, B is the top-ranked direction, and C comes from a second roll. The roll service was unreachable here, so the roll ran without its catalogue of outside challengers.

Kept on every page

Content stays visible without JavaScript. Reduced-motion is respected. Text meets WCAG AA contrast. Fonts are open-license and self-hosted, with no third-party font host. Nothing is invented: no ratings, quotes or numbers beyond what the site already states.

Retired

Paper & Ink, the cream ground, Newsreader + Inter, and the one template shared by every app page. Light or dark is now chosen per world from where people use the app, not forced on every page.
