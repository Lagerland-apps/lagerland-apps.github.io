I tuoi file restano sul tuo Mac." keywords: - mediakit privacy - informativa sulla privacy mediakit - mediakit dati personali - convertitore di file senza tracciamento - app senza tracciamento overview: > MediaKit è pensata per convertire, comprimere e trasformare i tuoi file interamente sul tuo Mac. I tuoi file sono affari tuoi. Questa informativa spiega quali informazioni MediaKit tratta, come vengono usate e quali scelte hai. data_collection: > MediaKit tratta i file che fornisci esplicitamente, trascinandoli, scegliendoli con il selettore di file o incollandoli dagli appunti. Sono compresi file video, audio, immagini, PDF, archivi ed ebook. Tutta l’elaborazione avviene in locale sul tuo Mac. MediaKit non raccoglie, non trasmette e non archivia alcun dato personale. data_storage: > Tutta l’elaborazione dei file avviene in memoria o in cartelle temporanee locali sul tuo Mac. MediaKit non gestisce server propri. I file di output vengono salvati nelle posizioni che scegli. Se scegli di usare funzioni di macOS come i backup o iCloud Drive, i tuoi file possono essere inclusi in base alle impostazioni del tuo sistema. third_parties: > MediaKit non usa servizi di terze parti per analisi, pubblicità o tracciamento. MediaKit non comunica con alcun server esterno. Tutta l’elaborazione usa framework nativi di Apple, tra cui AVFoundation, CoreImage, PDFKit, Vision, Speech e Compression. Apple può trattare una quantità limitata di dati nell’ambito dei servizi che scegli di usare, come App Store e gli acquisti in-app. refund_requests: intro: > Se chiedi ad Apple il rimborso di un acquisto in MediaKit, Apple può chiederci informazioni per aiutarla a decidere. Effettuando un acquisto, accetti che possiamo rispondere con le seguenti informazioni su quell’acquisto: items: - "se l’acquisto è stato consegnato e sbloccato nell’app" - "se era disponibile una versione gratuita dell’app prima del tuo acquisto" - "se preferiremmo che Apple approvasse o rifiutasse il rimborso" closing: > Non inviamo i tuoi file né altri dati personali, perché MediaKit elabora tutto sul tuo dispositivo e noi non li abbiamo. Apple prende la decisione finale su ogni rimborso. children: > MediaKit è uno strumento di conversione di file per uso generale e non è rivolto ai minori di 13 anni. Non raccogliamo consapevolmente dati personali da minori. changes: > Possiamo aggiornare questa informativa sulla privacy di tanto in tanto. Ogni modifica sarà riportata in questa pagina e la data di entrata in vigore sarà aggiornata di conseguenza. ---
